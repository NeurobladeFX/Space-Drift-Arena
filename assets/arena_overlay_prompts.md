# Transparent Arena Overlay Prompts

Use these prompts to create transparent PNG overlays that add atmospheric details and level-specific visual elements to the game arena. These should be rendered on top of the background.

**General Instructions:**
- Output as PNG with transparent background
- Size: 1920x1080 or larger
- 2D side scroller game style
- Elements should be semi-transparent or have transparency in strategic areas
- Focus on atmospheric effects, foreground elements, and level-specific details
