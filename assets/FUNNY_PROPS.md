Funny props used in-game (placeholders created automatically if missing)

- giant_duck: A giant rubber duck placed in several levels for a humorous easter egg.
- warning_sign: Large warning sign prop used in stations/volcanic base.
- disco_ball: (optional) Place in `cyber_city` or `space_station` for a fun dance area.

Notes:
- The game will draw simple SVG placeholders for these props if the image files are not present.
- If you want artist-made versions, name them as follows and upload to `assets/blocks/` or `assets/props/`:
  - `giant_duck.png` or `giant_duck.svg`
  - `warning_sign.png`
  - `disco_ball.png`
