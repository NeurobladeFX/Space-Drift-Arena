# Asset Prompts for All Levels - Mini Militia Style

## 📍 Where to Upload Assets
**Upload Location**: `e:\Space Drift Arena\assets\levels\`

All assets should be placed in this folder. The game will automatically load them based on the naming convention below.

---

## 🎨 General Style Guidelines

### Art Style
- **Mini Militia Inspired**: Clean, slightly cartoony but detailed
- **Rich Colors**: Vibrant, saturated colors matching each level's theme
- **Clear Outlines**: Environments should have clear, defined edges
- **Painterly Look**: Hand-painted texture quality, not photorealistic
- **Game-Ready**: Optimized for performance, clear gameplay readability

### Technical Specs
- **Format**: PNG with transparency where appropriate
- **Color Mode**: RGB
- **Background Images**: 3840x2160px
- **Visual Overlays**: 3840x2160px (transparent PNG)
- **Platform Tiles**: 256x128px (seamlessly tileable)
- **Obstacles/Props**: 512x512px minimum (will be scaled in-game)

## 💾 How to Use Assets in Your Game

### Step 1: Place Assets
1. Save all generated images to: `e:\Space Drift Arena\assets\levels\`
2. Follow the exact naming conventions specified above
3. Ensure files are PNG format with transparency where noted

### Step 2: Game Will Auto-Load
The game is already configured to automatically load these assets:
- Background images load in `Map.js` render method (line ~556)
- Visual overlays load in `Map.js` render method (line ~593)
- Platform tiles load in `renderPlatforms` method (line ~755)
- Obstacle images load via `assetsMap.js` configuration

### Step 3: Verify Loading
1. Start your game
2. Select a level
3. Check browser console (F12) for any loading errors
4. If an asset fails to load, the game will use procedural fallback rendering

### Step 4: Test Each Level
- Play through each level to see your assets in action
- Adjust asset colors/contrast if needed for gameplay visibility
- Ensure platforms are clearly distinguishable from backgrounds

## 🆘 Troubleshooting

**Asset not loading?**
- Check filename spelling exactly matches the naming convention
- Verify file is in `e:\Space Drift Arena\assets\levels\` folder
- Ensure file is PNG format
- Check browser console (F12) for specific error messages

**Asset looks wrong in-game?**
- Verify image dimensions match specifications
- Check if transparency is needed but missing
- Ensure colors are vibrant enough for game visibility
- Test on dark backgrounds if asset seems invisible

**Platform tiles not repeating correctly?**
- Ensure tile is truly seamless (test by placing two side-by-side)
- Verify dimensions are exactly 256x128px
- Check for edge artifacts or color shifts at boundaries
