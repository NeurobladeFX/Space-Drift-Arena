# Image Generation Prompts for Space Drift Arena

Use these prompts with an AI image generator (like Midjourney, DALL-E 3, or Stable Diffusion) to create game assets.

**CRITICAL REQUIREMENTS FOR ALL PLATFORM IMAGES:**
- **Side View Perspective**: All platforms must be shown from a side/profile view as if looking at them horizontally
- **Flat Top Surface**: The top edge must be flat and horizontal (this is where players stand)
- **Land-like Appearance**: Should look like solid ground/terrain that characters can stand on
- **2D Game Ready**: No perspective distortion, perfectly aligned for 2D side-scroller gameplay
